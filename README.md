# 🦵 ACL 康复专家 PT Skill

一个结构化的 AI 康复助手，专为 **前交叉韧带（ACL）重建术后恢复** 设计，尤其适用于复杂手术场景：

* ACL 重建（腘绳肌移植）
* 半月板修复（尤其后根修复）
* 髁间窝成型
* 多术式联合膝关节手术

该 Skill 可以将大模型（如 Claude）转化为一个**接近专业水平的康复治疗师助手**，帮助你进行：

* 📊 康复阶段判断
* 🏋️ 训练计划评估
* ⚠️ 风险识别（半月板 / 移植物 / 积液）
* 🧠 个性化康复调整
* 📈 恢复进度评分

---

## 🚀 功能特点

* ✅ 患者信息一次初始化，长期复用
* ✅ 标准化 JSON 输入输出
* ✅ 风险优先决策（半月板后根 > ACL进度）
* ✅ 基于临床逻辑分析（非泛泛建议）
* ✅ 支持每日康复跟踪

---

## 🧠 工作流程

### 1️⃣ 初始化患者信息（首次使用）

```json
{
  "术后天数": 212,
  "手术详情": {
    "前交叉韧带": "自体腘绳肌腱 + 高强线带增强",
    "内侧半月板": "成型",
    "外侧半月板后根": "穿骨道+纽扣钛板固定",
    "髁间窝成型": true
  },
  "风险标记": [
    "半月板后根修复",
    "ACL移植物成熟期",
    "髁间窝撞击风险"
  ]
}
```

---

### 2️⃣ 每日康复输入

```json
{
  "术后天数": 220,
  "训练计划": [
    {
      "动作": "深蹲",
      "负重": "60kg",
      "组数": 4,
      "次数": 8
    }
  ],
  "症状反馈": {
    "疼痛": [
      {
        "位置": "膝前侧",
        "程度": 2,
        "类型": "酸痛"
      }
    ],
    "肿胀": false,
    "皮温升高": false,
    "不稳定感": false
  },
  "功能表现": {
    "走路": "正常",
    "单腿站立秒数": 30
  }
}
```

---

## 📊 输出内容说明

AI 会返回以下结构化分析结果：

1. 康复阶段判断
2. 训练动作评估（✅ 合理 / ⚠️ 风险 / ❌ 禁止）
3. 个性化康复方案（具体到组数/次数）
4. 疼痛与风险分级（🟢 🟡 🔴）
5. 恢复评分（0–100）
6. 禁忌动作清单
7. 下一阶段重点

## ⚠️ 免责声明

本项目 **不构成医疗诊断或治疗建议**，仅用于：

* 康复知识辅助理解
* 自我训练记录与分析

如出现以下情况，请及时就医：

* 持续或加重的疼痛
* 明显肿胀或皮温升高
* 膝关节不稳定（打软腿）
* 疑似再次损伤
